| Action | Shortcut |
|---|---|
| New project | `Ctrl+N` |
| Open project | `Ctrl+O` |
| Open most recent project | `Ctrl+Shift+R` |
| Save | `Ctrl+S` |
| Refresh assets | `Ctrl+F5` |
| Exit | `Ctrl+Q` |
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` |
| Add greybox box / sphere | `Ctrl+B` / `Ctrl+Shift+B` |
| Import a glTF model | `Ctrl+I` |
| Edit selected object | `Ctrl+E` |
| Delete selected object | `Delete` |
| Move / rotate / scale tool | `1` / `2` / `3` |
| Snap to grid | `Ctrl+Shift+G` |
| Placement ray | `Ctrl+Shift+P` |
| Manage archetypes | `Ctrl+Shift+A` |
| Run or stop playtest | `F5` |
| Stop playtest | `Esc` |
| Open the documentation | `F1` |
| About | `F12` |
