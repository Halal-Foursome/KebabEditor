# KebabEditor

Десктопний 3D-редактор рівнів для платформера з вбудованим режимом плейтесту.

## Що це

KebabEditor дозволяє дизайнеру рівнів розставляти обʼєкти на 3D-сцені, редагувати їх
за допомогою гізмо (переміщення/оберт/масштаб) та одразу тестувати рівень, наприклад 
на правильність метрики об'єктів, розміщених на сцені.

Ключова ідея — **архетипи**: замість "голих" custom properties у glTF (`type=trigger`,
`action=...`), в редакторі це повноцінні ООП-обʼєкти (`Trigger`, `Collider`, `Enemy`
тощо) з типізованими параметрами. При експорті вони серіалізуються у стандартні
glTF `extras`, тож файл рівня залишається звичайним JSON, сумісним з іншими
інструментами.

## Фічі

- **3D-вʼюпорт** — навігація по сцені, рендер рівня (JOGL).
- **Гізмо** — переміщення, оберт, масштаб обʼєктів у сцені.
- **Архетипи обʼєктів** — бібліотека типів (Trigger, Collider, Enemy тощо)
  з власними типізованими параметрами; можна створювати нові архетипи.
- **Розміщення та редагування обʼєктів** — додавання інстансів архетипів
  на сцену, редагування їхніх властивостей.
- **Плейтест** — запуск рівня "на льоту" всередині редактора, без збірки
  окремої гри.
- **Проєкти та збереження** — керування проєктом, збереження/завантаження
  рівнів у форматі glTF.
- **Імпорт асетів** — використання зовнішніх 3D-моделей у рівні.

## Стек

- Java 25
- Swing + FlatLaf — UI редактора
- JOGL (OpenGL) — 3D-вʼюпорт, гізмо
- glTF — формат зберігання рівнів
- Gradle (Kotlin DSL, збірка проєктів)

## Статус

Проєкт на ранній стадії: реалізовано базовий UI-каркас (`MainWindow`, меню,
теми FlatLaf). 3D-рендеринг, модель сцени, архетипи та плейтест — у розробці.

## Структура

```
app/src/main/java/org/halalfoursome/kebabeditor/
|-- ui/            UI застосунку (MainWindow, меню)
|-- editor/        Координація редагування (Editor)
|-- project/       Керування проєктом (ProjectManager)
|-- utils/         Допоміжні класи (стилі, іконки, файлові діалоги)
```

## Архітектура

C4-модель проєкту (поточний стан + план) описана в DSL для Structurizr
(playground.structurizr.com).
